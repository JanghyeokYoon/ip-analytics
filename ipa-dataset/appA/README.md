# appA — 미국 특허 자료로 분석용 데이터셋 조립하기(프롬프트만 있다)

자료 기준일 2025-06-30. 이 데이터셋의 모든 기업·기관·특허·번호·인물·텍스트는 교육용으로 만든 가상의 것이며 실제 특허가 아니다.

- prompts.md: 부록 A의 프롬프트 2개. 준비, 먼저 보낼 말, 복사해 보낼 프롬프트를 차례로 적었다. 외부 서비스가 필요한 프롬프트에는 "진행 방법"을 더했다.

부록 A의 프롬프트 A.1·A.2는 실제 미국 특허 자료(PatentsView 대량 자료, Google Patents 공개 데이터셋, 유지료 사건 파일 등)를 받아 분석용 데이터셋을 조립하는 방법이다. 실습 데이터셋의 파일은 쓰지 않으므로 이 폴더에는 프롬프트 파일만 있다.

안내
- 조립을 마친 데이터셋의 모습은 다른 장 폴더의 정제본 파일(families.csv, documents.csv, citations.csv, applicants.csv, cpc.csv)과 같다. 열 정의는 그 폴더의 data_dictionary.csv와 책의 표 7.1·표 A.9를 본다.
- 실습 데이터셋의 번호는 가상 번호라 PatentsView에 없다.
