# 제품 사양서 — 고체 전해질 분말 2종

이 데이터셋의 모든 기업·기관·특허·번호·인물·텍스트는 교육용으로 만든 가상의 것이며 실제 특허가 아니다. 4장 소과제 1(청구항 대비)과 14장 소과제 2(FTO 1차 등급)에 쓴다.

## 제품 P-A (1년 뒤 양산)

| 항목 | 사양 |
|---|---|
| 조성 | 아지로다이트형 황화물 고체 전해질 Li5.5PS4.5Cl1.5 (x = 0.5 염소 과잉, 브롬 없음) |
| 결정 구조 | 입방정 아지로다이트(F-43m) 단일상, 유리상 없음(결정질) |
| 할로겐 | Cl만. Br·I 없음 |
| 산소 치환 | 없음 |
| 이온 전도도(25 ℃) | 4.2 mS/cm |
| 입자 크기 D50 | 1.0 µm |
| 소성 온도 | 500 ℃ (아르곤) |
| XRD LiCl 피크 강도비 | 0.08 (LiCl(200) ÷ 아지로다이트 최강 피크) |
| BET 비표면적 | 6.5 m²/g |
| 코팅 | 없음 |
| 용도 | 양극 복합체용 전해질 분말 |

## 제품 P-B (2년 뒤)

| 항목 | 사양 |
|---|---|
| 조성 | 혼합 할로겐 아지로다이트형 Li5.4PS4.4Cl0.8Br0.8 |
| 결정 구조 | 입방정 아지로다이트 단일상(결정질) |
| 할로겐 | Cl + Br (Br/(Cl+Br) = 0.5) |
| 산소 치환 | 1 몰% (황 자리의 일부를 산소로 치환) |
| 이온 전도도(25 ℃) | 7.5 mS/cm |
| 입자 크기 D50 | 2.5 µm |
| 소성 온도 | 480 ℃ (아르곤) |
| XRD LiCl 피크 강도비 | 0.03 |
| BET 비표면적 | 2.0 m²/g |
| 코팅 | 없음 |
| 용도 | 전해질층 및 양극 복합체용 분말 |

측정 조건: 이온 전도도는 25 ℃, 370 MPa 냉간 압축 펠릿의 교류 임피던스. D50은 레이저 회절. XRD는 CuKα. BET 비표면적은 질소 흡착.
