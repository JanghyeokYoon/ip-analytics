# 1장 프롬프트 — 지식재산과 IP 애널리틱스

『지식재산분석론』 1장의 프롬프트 1개를 복사해 쓸 수 있게 옮긴 파일이다(실습 데이터셋 ipa-dataset v2.6).

## 쓰는 법

1. "준비"에 적힌 파일을 이 폴더에서 찾아 대화형 AI에 업로드한다. 프로그래밍 환경은 필요 없다.
2. "먼저 보낼 말"이 있으면 복사해 보내고, 답이 준비와 README.md에 적힌 값과 같은지 본다. AI가 파일을 제대로 읽었는지 확인하는 단계다.
3. "프롬프트"를 복사해 같은 대화에 보낸다.

"진행 방법"은 세 가지를 적은 것이다. 외부 서비스가 있어야 하는 프롬프트의 실행 절차, 대화형 AI에서 할 때 알아 둘 점, 실제 자료나 더 큰 규모로 해 볼 때의 선택 절차다. 외부 서비스의 화면과 조건은 바뀌므로 책에는 무엇이 필요한지만 적고 절차는 이 파일에 적었다. 실습 전체의 안내는 최상위 폴더의 SETUP.md에 있다.

준비와 프롬프트는 책에 실린 글과 같다. 책의 프롬프트가 이 폴더의 파일 이름, 열 이름, 연도, 건수로 적혀 있기 때문이다. 책에서 "프롬프트 맨 아래에 붙인다"고 한 표는 이 파일의 프롬프트에 이미 붙여 두었고, 그런 곳은 "책에 더한 것"에 적었다. 책 본문의 표·그림·예제는 예제 데이터(5,400건)의 값이어서 이 폴더의 파일로 얻는 값과 다르다.

## 프롬프트 1.1 — 경영 질문을 하위 질문과 열로 나누기

**실행 환경**: 웹 대화형 AI만으로 가능

**준비**

- ① 파일 위치: 실습 데이터셋(ipa-dataset)은 장마다 폴더가 하나다(ch01~ch14, 부록은 appA~appC). 폴더마다 그 장의 데이터 파일과 README.md, data_dictionary.csv, prompts.md(복사해 쓸 프롬프트와, 외부 서비스가 필요한 프롬프트의 실행 절차)가 있다. 여기서는 ch01 폴더의 data_dictionary.csv와 families.csv를 쓴다.
- ② 데이터 사전 업로드: data_dictionary.csv(이 폴더 파일의 열 정의. file, column, type, description_ko, example의 다섯 열)를 먼저 업로드하고, "사전의 열 이름과 뜻을 요약해 보라"고 요청해 사전을 읽었는지 확인한다.
- ③ 패밀리 마스터 업로드: families.csv(한 행이 패밀리 한 건. family_id, assignee_std, priority_date, sub_tech, n_forward 등의 열)를 업로드하고 행 수와 열 이름을 묻는다. 행 수는 README.md의 파일 표와, 열 이름은 ②의 사전과 같아야 한다.
- ④ 같은 대화에서 아래 프롬프트를 보낸다.

**먼저 보낼 말 ①**

```text
첨부한 data_dictionary.csv는 데이터 사전이다(열: file, column, type, description_ko, example). 사전의 열 이름과 뜻을 요약해 줘.
```

**먼저 보낼 말 ②**

```text
첨부한 families.csv는 한 행이 패밀리 한 건이다. 행 수와 열 이름을 알려 줘.
```

**프롬프트**

```text
첨부한 data_dictionary.csv(열 이름과 정의의 목록)를 참고해, 경영 질문 "다음 3년 동안 고체 전해질 분야의 연구개발 예산을 늘려야 하는가"를 표로 바꿔 줘. 표의 열은 결정 조건, 하위 질문, 계산할 것, 필요한 열, 어떤 값이면 어느 선택지의 다섯 개로 하고, 결정 조건 하나를 한 행으로 해 줘.
필요한 열에는 data_dictionary.csv에 있는 열 이름만 쓰고, 사전에 없는 정보가 필요하면 "사전에 없음"으로 표시한 뒤 어디서 구할 수 있는지 적어 줘.
하위 질문은 집계하거나 비교할 수 있는 형태로 쓰고, 한 하위 질문의 계산은 두 개 이하로 해 줘.
```
