# 실습 안내 — 대화형 AI로 따라 하기 (ipa-dataset v2.6)

책의 프롬프트는 대화형 AI에 이 데이터셋의 파일을 업로드해 따라 할 수 있게 적었다. 프로그래밍 환경을 따로 갖출 필요는 없다. 이 파일은 실습하는 순서, 대화형 AI에서 자주 생기는 일, 외부 서비스가 필요한 프롬프트를 안내한다.

외부 서비스의 화면, 한도, 요금은 바뀐다. 그래서 책에는 무엇이 필요한지만 적고, 절차는 이 데이터셋의 파일에서 관리한다. 이 파일은 2026년 11월에 확인한 내용이다.

## 1. 필요한 것

| 책의 실행 환경 표기 | 뜻 | 준비 |
|---|---|---|
| 웹 대화형 AI만으로 가능 | 파일을 첨부하고 대화하는 생성형 AI 서비스 | 서비스 계정. 파일 첨부가 되는지 확인 |
| 코드 실행이 되는 대화형 AI(파일 첨부) | 첨부한 파일을 AI가 대화 안에서 직접 읽고 계산해 표·그래프·파일로 돌려주는 서비스 | 서비스 계정. 데이터 분석(코드 실행) 기능이 켜져 있는지 확인 |
| 외부 서비스 | 계정이나 신청이 필요한 외부 데이터 서비스 | 3절의 표와 해당 폴더의 prompts.md |

프롬프트 42개 가운데 38개는 이 데이터셋의 파일과 위의 두 환경만으로 끝까지 할 수 있다. 나머지 4개(6.3의 실제 자료 실행, A.1의 데이터 사전, A.2, B.2의 실행)는 외부 서비스나 자료가 있어야 한다. 외부 서비스가 필요한 부분을 뺀 프롬프트와 소과제의 계산 단계는 이 데이터셋의 파일로 실제로 실행해 확인했다(표준 계산 도구만 썼고, 가장 긴 단계가 20초 남짓이었다). 드는 시간과 알아 둘 점은 프롬프트마다 "진행 방법"에 적었다.

## 2. 실습하는 순서와 자주 생기는 일

1. 공부하는 장의 폴더에서 prompts.md를 연다.
2. "준비"에 적힌 파일을 대화형 AI에 업로드한다.
3. "먼저 보낼 말"을 복사해 보내고, 답한 행 수와 열 이름이 폴더의 README.md와 같은지 본다. 다르면 파일을 다시 업로드한다.
4. "프롬프트"를 복사해 같은 대화에 보낸다.
5. 답을 받으면 행 수와 합계가 "먼저 보낼 말"의 답과 맞는지부터 본다.

| 생기는 일 | 대처 |
|---|---|
| 파일이 한 번에 첨부되지 않는다 | 두세 번에 나누어 업로드한다. 그래도 안 되면 준비에 적힌 대로 필요한 열만 남기거나 파일을 나눈다 |
| 계산이 중간에 멈춘다 | "단계를 나누어 차례로 실행해 줘"라고 하거나, 지표·K·묶음을 하나씩 요청한다. 끝난 결과는 CSV로 저장하게 한다 |
| 필요한 도구가 없다고 한다 | 프롬프트에 적힌 대체 방법을 쓰게 한다. 적혀 있지 않으면 "도구 없이 직접 계산해 줘"라고 요청한다 |
| 대화가 길어져 앞의 파일을 다시 달라고 한다 | 새 대화를 열어 파일을 다시 업로드하고, 앞에서 저장한 결과 파일을 함께 첨부한다 |
| AI가 직접 읽고 판정할 일(분류, 개체 추출, 청구항 대조)을 코드의 키워드 규칙으로 바꾸어 한다 | "코드로 하지 말고 한 건씩 읽고 판정해 줘"라고 다시 지시한다. 읽을 분량이 많으면 25~50건씩 나누어 보낸다 |
| 결과 표가 길어 중간에 잘린다 | 묶음을 작게 나누어 받고, 묶음마다 CSV 파일로 저장하게 한 뒤 마지막에 합치게 한다 |
| 다시 실행하면 값이 조금 다르다 | 난수 시드가 프롬프트대로인지 확인한다. 분류처럼 AI가 판정하는 일은 실행마다 달라질 수 있으므로 책 5장의 방법으로 일치율을 본다 |
| 숫자가 책과 다르다 | 본문의 표·그림·예제는 예제 데이터의 값이고 이 데이터셋은 실습 파일이다. 값이 아니라 절차와 정의를 대조한다 |

## 4. (선택) 내 PC에서 Python 코드 실행하기

프롬프트 A.2와 3절의 선택 절차에서만 필요하다.

1. Python을 설치한다. python.org의 설치 파일이나 Anaconda 배포판을 쓴다. Windows 설치 화면에서는 PATH에 추가하는 선택 항목을 켠다.
2. 명령 창을 연다. Windows는 명령 프롬프트나 PowerShell, macOS는 터미널이다. `python --version`으로 설치를 확인한다.
3. 작업 폴더를 정하고 필요한 파일을 둔다.
4. 필요한 패키지를 설치한다. 예: `pip install pandas duckdb`
5. 대화형 AI에게서 받은 코드를 작업 폴더에 .py 파일로 저장한다. 코드가 읽는 파일 이름이 폴더의 파일 이름과 같은지 본다.
6. 명령 창에서 작업 폴더로 이동해(`cd 폴더경로`) `python 파일이름.py`로 실행한다.
7. 오류가 나면 오류 메시지 전체를 AI에게 보내 고치게 한다.

## 5. (선택) API 키 준비

수천 건의 분류나 추출을 자동화할 때만 필요하다.

1. 쓰려는 AI 서비스의 개발자용 사이트에 가입한다. API는 대화형 서비스의 구독과 따로 요금을 내는 경우가 많으므로 결제 조건을 먼저 확인한다.
2. API 키를 발급받는다. 키는 비밀번호처럼 다룬다. 코드, 문서, 공개 저장소에 적지 않는다.
3. 키를 환경 변수에 넣는다. 변수 이름은 서비스의 안내를 따른다. Windows는 `setx 변수이름 "키"`(새 명령 창부터 적용), macOS와 Linux는 `export 변수이름="키"`다.
4. 서비스가 안내하는 Python 호출 패키지를 `pip install`로 설치한다.
5. 사용 한도(월 지출 상한)를 서비스의 관리 화면에서 정해 둔다. 처음에는 한 묶음만 실행해 사용량과 비용을 확인한다.
6. 입력한 자료가 학습에 쓰이는지, 얼마 동안 보관되는지를 확인해 기록한다(책 5장의 보안 절).
