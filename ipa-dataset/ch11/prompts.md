# 11장 프롬프트 — 임베딩과 LLM으로 특허 의미 읽기

『지식재산분석론』 11장의 프롬프트 4개를 복사해 쓸 수 있게 옮긴 파일이다(실습 데이터셋 ipa-dataset v2.6).

## 쓰는 법

1. "준비"에 적힌 파일을 이 폴더에서 찾아 대화형 AI에 업로드한다. 프로그래밍 환경은 필요 없다.
2. "먼저 보낼 말"이 있으면 복사해 보내고, 답이 준비와 README.md에 적힌 값과 같은지 본다. AI가 파일을 제대로 읽었는지 확인하는 단계다.
3. "프롬프트"를 복사해 같은 대화에 보낸다.

"진행 방법"은 세 가지를 적은 것이다. 외부 서비스가 있어야 하는 프롬프트의 실행 절차, 대화형 AI에서 할 때 알아 둘 점, 실제 자료나 더 큰 규모로 해 볼 때의 선택 절차다. 외부 서비스의 화면과 조건은 바뀌므로 책에는 무엇이 필요한지만 적고 절차는 이 파일에 적었다. 실습 전체의 안내는 최상위 폴더의 SETUP.md에 있다.

준비와 프롬프트는 책에 실린 글과 같다. 책의 프롬프트가 이 폴더의 파일 이름, 열 이름, 연도, 건수로 적혀 있기 때문이다. 책에서 "프롬프트 맨 아래에 붙인다"고 한 표는 이 파일의 프롬프트에 이미 붙여 두었고, 그런 곳은 "책에 더한 것"에 적었다. 책 본문의 표·그림·예제는 예제 데이터(5,400건)의 값이어서 이 폴더의 파일로 얻는 값과 다르다.

## 프롬프트 11.1 — 유사 특허 검색과 구간별 임계값

**실행 환경**: 코드 실행이 되는 대화형 AI(파일 첨부)

**진행 방법**

외부 서비스는 필요 없다. 대화형 AI의 코드 실행기에서는 문장 임베딩 모델을 돌리기 어려워, 책의 프롬프트는 이 폴더의 embeddings_128d.csv(TF-IDF를 128차원으로 줄인 고정 임베딩)와 brief_similarity.csv(설계 설명문과의 유사도)를 쓴다. 만든 방법은 embeddings_meta.json에 있다.

문장 임베딩 모델로 직접 임베딩하려면(선택) 모델을 돌릴 수 있는 환경이 필요하다. 최상위 폴더 SETUP.md의 4절대로 내 PC에 Python을 준비하고, 대화형 AI에게 "corpus_part1.jsonl·corpus_part2.jsonl의 abstract와 first_claim을 문장 임베딩 모델로 임베딩해 CSV로 저장하는 코드를 써 줘"라고 요청해 받은 코드를 실행한다. 모델 파일은 처음 실행할 때 인터넷에서 다운로드된다. 만든 임베딩으로 같은 프롬프트를 다시 실행하고 상위 100건이 얼마나 겹치는지 적는다.

**준비**

- ① ch11 폴더의 embeddings_128d.csv·embeddings_meta.json(미리 만든 임베딩과 만든 방법), brief_similarity.csv(설명문과의 유사도·순위), corpus_part1.jsonl·corpus_part2.jsonl, design_brief.md, search_result.csv, README.md를 업로드하고 패밀리 수(5,598건)를 묻는다.
- ② 대화형 AI에서는 문장 임베딩 모델을 돌리기 어려워 미리 만든 임베딩을 쓴다. TF-IDF 유사도는 설명문(한글)을 영어로 옮기게 한 뒤 계산한다.
- ③ 판정 기록은 상위 100건을 직접 읽고 파일로 만들어 업로드한다.

**먼저 보낼 말**

```text
첨부한 embeddings_128d.csv의 행 수와 벡터의 차원, corpus_part1.jsonl과 corpus_part2.jsonl의 패밀리 수 합을 알려 줘.
```

**프롬프트**

```text
첨부한 embeddings_128d.csv를 family_id별 임베딩으로 쓰고, embeddings_meta.json에 적힌 만든 방법과 차원, 벡터가 L2 정규화되어 있는지를 먼저 보여 줘.
설계 설명문(design_brief.md)과의 코사인 유사도 순위(brief_similarity.csv)와 TF-IDF 유사도 순위를 역순위 융합(목록마다 1/(60 + 순위)의 합)으로 합쳐, 상위 100건을 융합 점수 내림차순 표(family_id, assignee_std, title, 유사도, 두 순위, 융합 점수)로 만들고, search_result.csv에 없는 패밀리는 cpc 열의 값과 함께 표시해 줘.
내가 상위 100건을 읽고 첨부한 판정 기록(family_id, 유사도, 관련 여부)으로 폭 0.10의 유사도 구간별 관련 비율과 윌슨 95% 구간을 계산해 "윌슨 하한 0.5 이상인 구간까지" 규칙의 임계값을 알려 주고, 임계값 바로 아래 구간의 검색식 밖 패밀리에서 시드 11로 40건을 무작위로 뽑아 줘. 사용한 코드와 라이브러리 버전도 보여 줘.
한 번에 끝내기 어려우면 단계를 나누어 차례로 실행하고, 단계마다 중간 결과를 보여 줘.
```

## 프롬프트 11.2 — 의미 맵과 k-평균 군집

**실행 환경**: 코드 실행이 되는 대화형 AI(파일 첨부)

**진행 방법**

외부 서비스는 필요 없다.

- k-평균과 실루엣 계수는 몇 초면 끝난다. 2차원 맵(t-SNE)은 20초 넘게 들 수 있으므로 군집 표를 먼저 받고 맵은 따로 요청한다.

**준비**

- ① ch11 폴더의 embeddings_128d.csv(직접 만든 임베딩이 있으면 그 파일), embeddings_meta.json, corpus_part1.jsonl·corpus_part2.jsonl, families.csv를 업로드한다.
- ② 임베딩의 행 수와 차원(5,598행, 128차원)을 묻고 같은 대화에서 아래 프롬프트를 보낸다.

**먼저 보낼 말**

```text
첨부한 embeddings_128d.csv의 행 수와 벡터의 차원을 알려 줘.
```

**프롬프트**

```text
첨부한 embeddings_128d.csv의 벡터(e000~e127)를 읽어 L2 정규화하고, 원래 차원에서 k-평균을 k = 5, 7, 9로 돌려 k마다 실루엣 계수 평균을 보여 줘. 난수 시드는 11, 초기 중심은 10번 바꾸어 돌려 줘.
실루엣이 높은 두 k에 대해 군집마다 건수, 중심에 가까운 특허 5건의 title, TF-IDF 상위 단어 10개, sub_tech 분포, 원래 공간의 k-최근접 이웃 밀도(가장 가까운 10건과의 코사인 유사도 평균) 중앙값을 한 표로 만들어 줘. title·abstract는 corpus_part1.jsonl·corpus_part2.jsonl에서, sub_tech는 families.csv에서 family_id로 붙이고 없으면 "밖"으로 둬.
UMAP(n_neighbors = 15, min_dist = 0.1, 시드 11. 쓸 수 없으면 t-SNE, 시드 11로 대신하고 그렇게 적는다) 맵에 실루엣이 더 높은 k의 군집을 색으로 칠하고 좌표는 CSV 파일로 저장해 줘. 사용한 코드와 라이브러리 버전도 보여 줘.
한 번에 끝내기 어려우면 단계를 나누어 차례로 실행하고, 단계마다 중간 결과를 보여 줘.
```

## 프롬프트 11.3 — 텍스트 신규성 백분위와 돌파형 지수

**실행 환경**: 코드 실행이 되는 대화형 AI(파일 첨부)

**준비**

- ① ch11 폴더의 embeddings_128d.csv(프롬프트 11.1에서 직접 만든 임베딩이 있으면 그 파일)와 families.csv(family_id, assignee_std, priority_date, sub_tech)를 업로드하고, 두 파일의 행 수와 priority_date가 날짜로 읽혔는지 묻는다.
- ② 실습 파일의 우선 연도는 2014~2023년이다. 앞 5년 창이 온전한 연도는 2019~2023년이고, 앞뒤 창이 모두 온전한 연도는 없어 FS와 q는 빈값으로 나온다(본문 예제는 2010~2024년 자료라 2015~2019년에 FS와 q가 있다).

**먼저 보낼 말**

```text
첨부한 embeddings_128d.csv와 families.csv의 행 수를 알려 주고, priority_date가 날짜로 읽혔는지 확인해 줘.
```

**프롬프트**

```text
첨부한 embeddings_128d.csv를 families.csv와 family_id로 결합하고(결합되지 않는 패밀리는 뺀다), 앞 5년 창이 온전한 우선 연도(2019~2023년)의 패밀리마다 priority_date가 그 패밀리의 우선일 앞 5년 안인 다른 패밀리와의 코사인 유사도 최댓값, 평균(BS), 창 안 패밀리 수를 구해 줘.
Nov = 1 − 최댓값을 같은 우선 연도 안의 백분위(Nov가 자기 이하인 비율 × 100)로 바꾸고, 뒤따르는 5년 창도 온전한 우선 연도가 있으면 그 패밀리의 FS(그 창의 유사도 평균)와 q = FS/BS도 계산하고, 없으면 없다고 알려 줘.
family_id, assignee_std, priority_date, sub_tech, Nov, 신규성 백분위, BS, FS, q의 표(신규성 백분위 내림차순)와 우선 연도별 Nov 중앙값·창 안 패밀리 수를 보여 줘. 사용한 코드와 라이브러리 버전도 보여 줘.
한 번에 끝내기 어려우면 단계를 나누어 차례로 실행하고, 단계마다 중간 결과를 보여 줘.
```

## 프롬프트 11.4 — 자체 분류 체계의 분류와 검증

**실행 환경**: 코드 실행이 되는 대화형 AI(파일 첨부)

**진행 방법**

외부 서비스는 필요 없다. 이 분류는 AI가 초록을 직접 읽고 판정하는 일이다.

- AI가 키워드 규칙으로 분류하려 하면 "한 건씩 초록을 읽고 판정해 줘"라고 다시 지시한다.
- 100건을 한 번에 읽지 못하면 50건씩 나누어 요청하고, 사람 판정(rater_a)과의 비교는 100건을 모두 마친 뒤에 시킨다.

**준비**

- ch11 폴더의 eval_sample.csv(표본 100건의 사람 판정. family_id, rater_a, rater_b), corpus_part1.jsonl·corpus_part2.jsonl(title, abstract 등), README.md를 업로드하고, eval_sample.csv의 100건이 모두 corpus 파일에 있는지 묻는다. 대화형 AI가 100건을 한 번에 읽지 못하면 50건씩 나누어 요청한다.

**먼저 보낼 말**

```text
첨부한 eval_sample.csv의 family_id 100건이 모두 corpus_part1.jsonl·corpus_part2.jsonl에 있는지 알려 줘.
```

**프롬프트**

```text
첨부한 eval_sample.csv의 100건마다 corpus_part1.jsonl·corpus_part2.jsonl에서 title과 abstract를 찾아 읽고 각 특허를 (1) 조성: 고체 전해질의 조성·결정 구조, (2) 계면: 전해질과 양극 사이의 코팅층(할라이드 코팅층 포함)과 리튬금속 음극 쪽 계면층, (3) 공정: 전해질의 합성·소결과 시트·막 성형, (4) 범위 밖 가운데 하나에 배정해 줘.
할라이드 화합물이 전해질 입자나 양극 표면의 코팅층이면 (2), 전해질 자체의 조성이면 (1)이야. 두 분류 모두에 해당하면 초록의 주된 대상으로 정하고, 어려우면 "판단 보류"와 이유를 적어 줘. 결과는 family_id, 분류(조성·계면·공정·범위밖), 근거가 된 초록 문장, 확신도(높음/중간/낮음)의 표로 입력 순서대로 만들어 줘.
분류를 마친 뒤에만 사람 판정 열(rater_a)을 읽어 비교하고 교차표, 정확도, 카파와 부트스트랩 95% 구간(10,000번, 시드 11), 분류별 재현율·정밀도와 윌슨 95% 구간, 확신도별 일치율을 계산해 줘. 모델 이름·버전, 처리한 행 수, 사용한 코드도 보여 줘.
```
