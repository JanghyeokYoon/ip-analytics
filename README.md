# 지식재산분석론 (IP Analytics) — 실습 데이터셋과 부록

『지식재산분석론(IP Analytics)』(윤장혁 지음)의 독자를 위한 온라인 자료다. 이 저장소에는 두 가지 자료가 있다.

- 실습 데이터셋(`ipa-dataset` 폴더): 책의 프롬프트와 소과제를 따라 할 때 쓰는 가상 특허 데이터셋이다.
- 부록 A~C(PDF 세 개): 특허 데이터의 구조와 책의 계산에 쓰는 수학·통계 도구를 설명한다.

**실습 데이터셋의 모든 기업·기관·특허·번호·인물·텍스트는 교육용으로 만든 가상의 것이며 실제 특허가 아니다.** 실제 특허 검색이나 법적 판단에 쓰지 않는다.

## 처음 쓰는 순서

1. 이 화면의 초록색 Code 단추에서 Download ZIP을 눌러 저장소 전체를 다운로드하고 압축을 푼다.
2. [ipa-dataset/README.md](ipa-dataset/README.md)에서 폴더 구성과 파일 형식을 확인한다.
3. [ipa-dataset/SETUP.md](ipa-dataset/SETUP.md)에서 대화형 AI로 실습하는 순서를 읽는다.
4. 공부하는 장의 폴더를 열고 prompts.md를 따라 한다. 8장이면 `ipa-dataset/ch08` 폴더다.

## 부록과 실습 데이터셋의 관계

부록은 실습 데이터셋의 파일이 어떤 특허 자료를 본뜬 것인지 설명한다. 부록을 먼저 읽으면 파일과 열의 뜻을 빠르게 파악할 수 있다.

| 부록 | 설명하는 내용 | 관련 폴더와 파일 |
|---|---|---|
| 부록 A | 미국 특허상표청 자료의 테이블과 결합 키, 유지료·존속기간·양도 기록, 분석용 데이터셋을 조립하는 방법 | `appA` 폴더의 프롬프트. 조립한 결과의 모습은 장 폴더의 families.csv, documents.csv, citations.csv, applicants.csv, cpc.csv와 같다 |
| 부록 B | 한국 특허 자료와 번호 체계, 한국 법적 상태, PATSTAT의 테이블, 패밀리와 법적 사건 | `appB` 폴더의 kr_patents.csv, kr_annual_fees.csv, kr_admin_events.csv, kr_rights_events.csv, family_publications.csv |
| 부록 C | 로그·비율·증가율, 정규화, 구간, 부트스트랩, 검정, 평가 지표 | `appC` 폴더의 프롬프트(부트스트랩 구간과 순위 안정성 점검) |
